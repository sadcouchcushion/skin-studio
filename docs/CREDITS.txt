Included in the download
These files ship unchanged inside the Skin Studio zip. Each stays under its own licence, and their authors own them.

- repak-rivals (retoc-rivals-cli 3.8.0) by natimerry, spuds and Truman Kilen (trumank). Extracts and packs Marvel Rivals .pak/.utoc/.ucas files. MIT or Apache-2.0; licence files are in tools/rrcli/. Nexus mod 1717 (https://www.nexusmods.com/marvelrivals/mods/1717) · GitHub (https://github.com/natimerry/repak-rivals)
- retoc 0.1.5 by Truman Kilen (trumank) and Archengius. Unreal IoStore packer. MIT. GitHub (https://github.com/trumank/retoc)
- UE4-DDS-Tools 0.6.1 by matyalatte. Texture extraction and injection. MIT. GitHub (https://github.com/matyalatte/UE4-DDS-Tools)
- Texconv-Custom-DLL (texconv.dll, part of UE4-DDS-Tools) by matyalatte, based on Microsoft's Texconv / DirectXTex (https://github.com/microsoft/DirectXTex). MIT. GitHub (https://github.com/matyalatte/Texconv-Custom-DLL)
- Python 3.10.11 embeddable package (part of UE4-DDS-Tools) by the Python Software Foundation. PSF License v2; licence in tools/ddstools/python/. python.org (https://www.python.org)
- UAssetAPI 1.0.2 by atenfyr. Reads and writes material colours in SkinColorTool. MIT. GitHub (https://github.com/atenfyr/UAssetAPI)
- Newtonsoft.Json by James Newton-King. MIT. GitHub (https://github.com/JamesNK/Newtonsoft.Json)
- ZstdSharp by Oleg Stepanischev. MIT. GitHub (https://github.com/oleg-st/ZstdSharp)
- Microsoft WebView2 SDK 1.0.2957.106 by Microsoft Corporation. Runs the 3D preview window. BSD-style licence (notice below). NuGet (https://www.nuget.org/packages/Microsoft.Web.WebView2)
- three.js r185 by the three.js authors. The 3D preview. MIT. threejs.org (https://threejs.org)
- Black Ops One font by James Grieshaber and Eben Sorkin (The Black-Ops Project Authors). SIL Open Font License 1.1; licence in branding/. Google Fonts (https://fonts.google.com/specimen/Black+Ops+One)
- Oodle decompressor (oo2core_9_win64.dll) by Epic Games Tools (RAD Game Tools). Proprietary; shipped as it comes with repak-rivals. radgametools.com (https://www.radgametools.com/oodle.htm)
- Marvel.usmap: Marvel Rivals type mappings, generated from the game files and shared by the Marvel Rivals modding community.

Used, not included
Skin Studio works with these, but they are not in the download.

- Unreal Engine 5.3 by Epic Games. Used to cook the in-game panel's widget assets. Unreal Engine EULA. unrealengine.com (https://www.unrealengine.com)
- Project Galacta by 0xSaturn (optional). Swaps a freshly built mod into the running game with F7. Nexus mod 12806 (https://www.nexusmods.com/marvelrivals/mods/12806)
- Atelier by clownfetus (optional). 3D preview meshes and Atelier project round-trips; Skin Studio runs its tools and copies none of its code. GPL-3.0. GitHub (https://github.com/clownfetus/Atelier)
- CUE4Parse by FabianFG and contributors (inside Atelier and FModel). Decodes game meshes. Apache-2.0. GitHub (https://github.com/FabianFG/CUE4Parse)
- FModel by 4sval and contributors (optional). Mesh export for the Blender bridge. GPL-3.0. GitHub (https://github.com/4sval/FModel)
- Blender by the Blender Foundation (optional). 3D painting. GPL. blender.org (https://www.blender.org)
- .NET 8 Runtime by Microsoft / .NET Foundation. Runs SkinColorTool. MIT. dotnet.microsoft.com (https://dotnet.microsoft.com)
